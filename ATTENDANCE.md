# Отчёт по посещаемости

«Статистика → Отчёт по посещаемости». Кнопка на странице отметки посещений открывает ту же вкладку.
Доступ — существующее право visits.view («Журнал и статистика посещений»).
Сотрудник с этим правом видит раздел статистики даже без statistics.view;
это не открывает ему отчёты по фонду и работе сотрудников.
Просмотр карточки из детализации дополнительно требует readers.registry.view.

## Расчёт

Источник — library_visits, связанные reader_profiles, пункты и сотрудники.
Выдача книги, регистрация читателя и вход на сайт не создают посещений.
Повторные сканы уже исключаются регистрацией в пределах 10 минут.
Фильтры применяются до агрегации в SQL. Отчёт ничего не записывает в базу.

Таблица: дата/период, бакалавры (БАК), магистранты (МАГ), преподаватели/ППС (ПОҚ),
сотрудники, внешние пользователи, всего посещений, уникальные читатели.
Докторанты и прочие категории появляются отдельными колонками при наличии визитов.
Каждый читатель входит ровно в одну колонку:
- teacher, faculty или is_teaching_staff=true → ППС;
- bachelor, master, staff, external, doctoral → соответствующая колонка;
- остальные, включая student, specialist и исследователей без признака ППС → прочие.

Неподтверждённая степень не приравнивается к бакалавриату. Прочие не считаются внешними.
Для ручной регистрации внешних пользователей добавлена категория external и код билета E.
Имеющиеся билеты, категории и синхронизация автоматически не меняются.

Категория, факультет и другие сведения — **текущее состояние карточки**.
Снимков этих полей на момент визита нет; после изменения карточки историческая
разбивка пересчитывается. Это указано в интерфейсе и выгрузке.

Даты включительны, время — LIBRARY_TIMEZONE (по умолчанию Asia/Almaty).
UTC преобразуется с учётом исторических правил часового пояса.
Пустые дни включены. При выборе дней недели остальные даты исключены.
Среднее — визиты / число выбранных календарных дат, включая нулевые.
Уникальные читатели за неделю, месяц и период вычисляются заново;
складывать дневные или месячные уникальные показатели нельзя.
В разрезе пунктов/часов один читатель может присутствовать в нескольких группах.

## Фильтрация и представление

Период до 3660 дней; пресеты сегодня, 7 дней, этот/прошлый месяц, учебный/календарный год.
Строки по дням, неделям или месяцам; дневная таблица содержит месячные итоги.
Несколько значений одного фильтра — «ИЛИ», разные фильтры — «И».

Фильтры: группа отчёта, категория, статус, факультет, кафедра, образовательная программа,
группа, курс, год поступления, пункт **фактического визита**, сотрудник отметки,
точка отметки, дни недели, время суток, ФИО/билет/штрихкод.
«Не указано» ищет пустые значения. Закрытые пункты сохраняют историю.
Время до включает всю указанную минуту; 22:00–08:00 выбирает часы через полночь.
Учебный год начинается 1 сентября. Праздники автоматически не исключаются.

Подробная разбивка: факультет, кафедра, программа, группа, курс, год поступления,
пункт, сотрудник, точка отметки, категория, статус.
Диаграммы: временной ряд, часы, дни недели, группы читателей.
Переключение между посещениями и уникальными читателями.
Точные значения доступны в таблицах, в том числе с клавиатуры.

Детализация по дате, категории или группе использует те же фильтры и пагинацию.
Изменение формы не меняет показанный отчёт до «Применить».
Excel/CSV содержат **всю применённую выборку**, включая месячные/общие итоги,
разбивку, часы, дни недели, условия и правила, а не только текущую страницу.
Строковые ячейки защищены от выполнения формул.

## API и эксплуатация

- GET /api/statistics/attendance
- GET /api/statistics/attendance/options
- GET /api/statistics/attendance/journal (offset, limit до 100)
- GET /api/statistics/attendance/export?format=xlsx|csv

Общие параметры: date_from, date_to, group_by=day|week|month, breakdown, q,
time_from, time_to. Множественные фильтры — повторяющиеся параметры:
faculty=Факультет1&faculty=Факультет2. Пустое значение — faculty=.
Дни недели: weekday=0 (Пн) … weekday=6 (Вс).
Остальные имена соответствуют полям, см. Filters в attendance.py.

Сеансовая авторизация обязательна. Ответы private, no-store.
ИИН, даты рождения, контакты, фотографии и примечания не передаются отчётом.
Поисковые параметры скрыты в access-log аналогично поиску читателей.

Миграция БД не нужна. Обновить API и web с сохранением Compose overlays.
Код: backend/app/attendance.py, AttendancePage.vue, AttendanceFilter.vue.
Проверки: backend/tests/test_attendance.py, регрессия читателей/авторизации.
