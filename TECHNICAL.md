# Автоматические служебные поля

При сохранении сервер формирует выбранные в профиле служебные поля:

- 001: постоянный номер CAT + UUID, если исходного номера нет. Существующий номер и импортированный номер сохраняются. Внешние номера не проверяются на уникальность без учёта организации-источника.
- 005: дата и время изменения, UTC, 16 символов. Последовательные изменения внутри одной десятой секунды получают разные значения.
- 008: дата создания (Asia/Almaty) и 34 неопределённые позиции. Для новой автоматически созданной строки однозначный год берётся из 260$c/264$c, единственный трёхбуквенный язык — из 041$a. Готовая строка не пересобирается автоматически при изменении других полей.
- Локальные 990$d/e/f: даты создания. Существующие значения не перезаписываются. Старые записи без известной даты создания не получают сегодняшнюю дату задним числом.
- 000: для новой книги/статьи с начальным шаблонным маркером устанавливается уровень m/a; при изменении обычной записи статус n становится c. Остальные позиции исходного маркера сохраняются. Расчёт длины ISO 2709 и смещений относится к будущему экспорту.

В форме эти строки защищены от обычного ввода, удаления и дублирования. Экспертный JSON доступен, но сервер защищает существующий номер и даты создания независимо от способа редактирования.

«Настроить характеристики» редактирует общие позиции 008: характер даты, две даты, язык, место издания. Другие позиции не меняются. Специальные характеристики отдельных материалов остаются в экспертном JSON. В панели предусмотрен краткий список языков и стран, исходные коды сохраняются; другое место можно задать кодом MARC. Источник кодов: https://www.loc.gov/marc/countries/countries_code.html . ISO-коды автоматически не конвертируются. Неверный формат изменённых общих позиций отклоняется; исходные неизвестные позиции не исправляются автоматически.

Оператор 097$b остаётся ручным: общий ключ доступа не определяет сотрудника. Потребуются персональные учётные записи. Обновление приложения само по себе не меняет существующие записи. Автоматические поля появляются при сохранении.

Вход выполняется по логину и паролю (AUTH.md). Интеграционный ключ только для импорта задаётся ADMIN_KEY в .env. Этот файл не включён в ZIP проекта.

Проверка: 23 теста сервера прошли; production-сборка прошла. В браузере вручную проверены вход admin, недоступность удаления 001, служебные поля только для чтения, выбор страны/языка и изменение года в 008 без сохранения тестовых записей. Автономный Chrome-сценарий оставлен в frontend/tests/technical-browser.cjs; запуск остановлен из-за задержки чтения локальных зависимостей, проверка выполнена во встроенном браузере.
