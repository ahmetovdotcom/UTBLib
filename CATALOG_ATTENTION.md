# Записи, требующие внимания

Раздел «Каталогизация и классификация → Требует внимания» доступен с правом `catalog.view`. Кнопка перехода есть также над каталогом. Редактирование открытой карточки по-прежнему требует `catalog.edit`.

Выберите поля или подполя из полного списка MARC и локальных определений, тип документа (или все типы) и проверки:

- **Не заполнено**: поле отсутствует или содержит только пустые строки/пробелы. Для целого поля достаточно любого непустого подполя; для выбранного подполя — любого его непустого повторения. Маркер 000 читается из `leader`.
- **Значение вне справочника**: каждое непустое значение сверяется с текущим справочником соответствующего типа документа. Проверяются и импортированные, и ранее сохранённые значения. Сравнение использует NFC и удаление пробелов по краям, как основной справочник; регистр значим.

Если `auto_add=true`, новые значения допустимы и не отмечаются. Если включён только `allow_edit`, значение вне списка показывается для проверки с пояснением, хотя сохранять его разрешено. Поля без подключённого справочника не проверяются на принадлежность списку. `097$b` «Оператор» исключён из этой проверки, поскольку список сотрудников является рекомендацией и старые имена допустимы. Отсутствие значения проверяется независимо от этих настроек.

Любая найденная проблема включает запись в результат. Запись выводится один раз со всеми причинами. Выбор целого поля включает проверку справочников всех его настроенных подполей. Несколько выбранных проверок объединяются по «или», поэтому числа в карточках причин могут пересекаться.

Проверка ничего не изменяет, не пополняет справочники и не исправляет MARC автоматически. Она не оценивает смысловую правильность библиографического описания. После исправления карточки возврат в список выполняет проверку заново. Фильтры и страница хранятся в пользовательском `authStorage` на время сеанса браузера.

API: `GET /api/catalog-attention/options` и `GET /api/catalog-attention`. У отчёта повторяющиеся параметры `fields=952$j`, `checks=missing`, `checks=vocabulary`, необязательные `type_id`, `q`, `offset`, `limit`. Не более 100 выбранных полей и 100 результатов на странице. Записи проверяются до пагинации; память ограничена пакетами по 250 записей, справочники загружаются без запросов на каждую запись. Полный проход нужен для точных итогов. Отдельная таблица ошибок и миграция не требуются.

Код: `backend/app/catalog_attention.py`, `frontend/src/CatalogAttention.vue`. Проверки: `backend/tests/test_catalog_attention.py`.
