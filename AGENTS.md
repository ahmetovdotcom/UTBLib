# Инструкции для ИИ-агента UTBLib

Перед началом работы прочитай [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md): там контекст, архитектура, решения владельца, ограничения интеграций и известные незавершённые задачи.

- MARCSQL только для чтения; импорт пользователь запускает самостоятельно. Последняя политика: добавлять новые записи/экземпляры, сохранять существующие данные UTBLib.
- Сохраняй рабочую БД, историю учёта и действующий старый сайт. Не удаляй Docker volumes и не запускай очистку ради обновления.
- Не помещай секреты и персональные данные в Git, документацию и логи. Используй приватные env-файлы.
- Перед изменениями проверь git status; тестируй операции учёта на изолированных данных.
- При обновлении сохраняй фактические Compose overlays и окружение читателей/книговыдачи.
- Общайся по-русски. Различай локальное изменение, commit, push и deploy; сообщай только подтверждённые результаты.
- Обновляй PROJECT_HANDOFF.md при существенных изменениях архитектуры и договорённостей. Текущие инструкции пользователя приоритетнее исторического контекста.
