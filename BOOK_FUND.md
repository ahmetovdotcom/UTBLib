# Книжный фонд

Раздел «Статистика → Книжный фонд» показывает текущее количество экземпляров, а не число карточек или историческую сумму поступлений. Доступ — `statistics.view` («Просмотр статистики»). API: `GET /api/statistics/book-fund`.

Учитываются `copies.status=active`: отдельно созданные/импортированные экземпляры и экземпляры проведённых (`posted`) поступлений. Связь с каталогом — `copies.record_id` либо `acquisition_lines.record_id`. Количество в строке поступления не используется. Книги на руках, в резерве и на ремонте остаются в фонде; списанные/отменённые исключены. Отчёт не меняет учёт, КСУ или каталог. Карточки без экземпляров дают ноль. Миграции БД не нужны.

Строки: учебная, учебно-методическая, научная, справочная, художественная; при необходимости — «Прочая / вид не определён». Основной источник — стандартные коды `952$a`:

| Код | Строка |
| --- | --- |
| КУК, КУР, КУИ | Учебная |
| КУМК, КУМР, МИ/… | Учебно-методическая |
| КНК, КНР, КНИ | Научная |
| КСК, КСР, КСИ | Справочная |
| КХК, КХР, КХИ | Художественная |

При пустом `952$a` используются однозначные распознанные названия из `952$c` (таблица `LABEL_KINDS` в `book_fund.py`). Явное учебно-методическое значение также уточняет общий код КУ. Несколько несовместимых кодов или неизвестный код не угадываются, остаются в «Прочая / вид не определён». Общие КСУ-настройки не меняются: первый лист объединяет учебную и методическую литературу, новый отчёт разделяет их.

Однозначно обозначенные кодами CD, АУД, ВИД, ДК электронные/аудиовизуальные материалы считаются отдельно, за пределами книжного фонда. Брошюры, авторефераты, выпуски журналов и неуточнённые материалы не пропадают: без определённой категории они видны в строке «Прочая / вид не определён».

Колонки: всего, на государственном (казахском) языке, на русском языке. При ненулевых значениях показываются иностранные, многоязычные и «Язык не уточнён». Язык берётся из `041$a`, при отсутствии — из стандартного кода `952$a`; противоречие даёт неуточнённый язык. Поддержаны отдельные/разделённые/сцепленные трёхбуквенные коды, несколько языков дают одну многоязычную колонку. Повторы одного языка не делают книгу многоязычной. Отчёт не является валидатором полного списка ISO-кодов: прочие трёхбуквенные коды (кроме und/zxx/unk/mul) относятся к иностранным, как в существующем КСУ.

Каждый учитываемый экземпляр входит ровно в одну строку и одну языковую колонку. Их суммы равны общему итогу. Число требующих уточнения экземпляров считает объединение проблем по категории/языку, без двойного счёта. На экране видна дата/время расчёта по Алматы. После изменений учёта/каталога нажать «Обновить» или заново открыть раздел.

«Скачать CSV» выгружает показанный снимок таблицы с числовыми значениями, датой и пояснениями (UTF-8 BOM, разделитель `;`). Прошлые годы не реконструируются: для исторического фонда потребуется отдельная договорённость о снимках/событиях. Числа из пользовательского фото — только образец оформления.

Код: `backend/app/book_fund.py`, `frontend/src/BookFundPage.vue`. Тесты `backend/tests/test_book_fund.py` проверяют классификацию, обе связи экземпляров, сверку итогов, исправление каталога, исключение отмен/списаний, выдачу/возврат и права. БД в тестах изолирована.
