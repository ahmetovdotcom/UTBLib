# Статистика книговыдачи и копирование описания

## Работа с отчётом

Откройте **Статистика → Книговыдача**, выберите период и нажмите **Сформировать**.
Группировки: библиографическая запись, категория/вид литературы, специальность,
дисциплина, язык, тип документа, пункт обслуживания, категория читателя.
Фильтры можно сочетать; внутри одного фильтра можно выбрать несколько значений.
Поиск — по заглавию, автору, ISBN или номеру записи. Варианты фильтров сформированы
по книгам, которые выдавались; при отсутствии метаданных есть группа «Не указано».

По каждой книге видны число выдач, разных читателей и разных экземпляров.
Повторные выдачи одному человеку увеличивают число выдач, но не число читателей.
Нажатие на специальность, язык или другую группу открывает её список книг.
Доступны динамика по дням/месяцам, восемь наиболее востребованных групп,
сортировка и Excel/CSV всех строк с фильтрами и пояснениями.
Выгрузка использует параметры последнего сформированного отчёта.

## Правила расчёта

- Источник — `loans`, одна строка равна одной выдаче экземпляра. Продления из
  `loan_events` не создают новых выдач в отчёте. Возвраты, утраты и последующее
  списание экземпляра не убирают состоявшиеся выдачи.
- Период включает обе даты по времени `Asia/Almaty`, фильтруется по `issued_at`.
  По умолчанию выбран текущий месяц до сегодня. Максимум — 3660 дней.
  Для периодов более 93 календарных дней диаграмма сгруппирована по месяцам.
- Связь с записью: `copies.record_id`, при его отсутствии —
  `copies.line_id → acquisition_lines.record_id`.
- Книги группируются по `record_id`, одинаковое заглавие разных записей не
  объединяет их. Статистика не включает записи, которые не выдавались в периоде.
- Специальность — `952$j`, дисциплина — `952$i`, вид литературы — `952$c`.
  Категория литературы определяется существующим классификатором книжного фонда
  (`952$a`, резерв/уточнение `952$c`). Язык — `041$a`, резерв `008/35–37`, затем
  классификация `952`; составные коды языков разбираются на отдельные значения.
- Метаданные книги и категория читателя берутся из **текущих** карточек.
  Изменение карточки может изменить группировку прежних выдач.
- При нескольких специальностях, дисциплинах или языках одна выдача входит
  в каждую подходящую группу один раз. Дубли одинаковых значений не умножают её.
  Общие итоги рассчитываются отдельно без повторов; сумму групп нельзя считать
  общим итогом. То же относится к уникальным читателям по дням и группам.
- Фильтры соединяются через И; значения внутри одного фильтра — через ИЛИ.
  Если у книги две специальности и выбрана одна, книга проходит фильтр, а
  группировка всё равно показывает все её специальности.
- Импорт каталога и экземпляров MARCSQL не импортирует историю книговыдачи.
  В отчёте есть только выдачи, зарегистрированные в UTBLib.

## Копирование библиографического описания

В каждой строке общего каталога есть кнопка **Копировать**. Она получает описание
текущей сохранённой записи через имеющийся генератор `gost.describe` и кладёт
обычный текст в буфер обмена. Для статей определяется компонентное описание по
уровню записи в маркере MARC; при наличии включается описание журнала/сборника.
Сохранение или дублирование записи не выполняется. При запрете буфера обмена
браузером открывается выделенный текст для Ctrl+C/⌘C; ложного успеха нет.

## Код и API

- `backend/app/circulation_statistics.py`, `frontend/src/CirculationStatistics.vue`.
- `GET /api/statistics/circulation` — JSON отчёт; `/options` — варианты фильтров;
  `/export?format=xlsx|csv` — вся выборка. Право: `statistics.view`.
- Параметры: `date_from`, `date_to`, `group_by`, `q`, `record_id`, повторяемые
  `kind`, `literature_type`, `specialty`, `discipline`, `language`,
  `document_type`, `branch_id`, `category`. Ключ группировки записей — `record`.
- `GET /api/records/{id}/description` возвращает `id`, `version`, `text`, `html`
  существующего генератора. Право: `catalog.view`; копируется только `text`.
- `frontend/src/CopyDescription.vue` используется в каталоге и деталях отчёта.
- Отчёт не возвращает ФИО или идентификаторы читателей. Ячейки выгрузки защищены
  от интерпретации пользовательских значений как формул.
- Новых зависимостей, переменных окружения и миграций БД нет.
