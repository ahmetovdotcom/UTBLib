# Труды сотрудников

В рабочем листе каталога есть отметка «Труды ППС»; при её включении доступны загрузка
PDF до 50 МБ и «Взять первую страницу как обложку». Файл необязателен. Изменения
публикуются только вместе с сохранением записи. Чтобы убрать книгу из раздела,
снимите «Труды ППС»; сохранённый файл остаётся у записи, но читателям недоступен.
«Убрать файл» удаляет PDF и обложку только после сохранения.

В library `/faculty-works` использует существующий каталог с отдельной выборкой,
поиском, фильтрами, сортировкой и пагинацией. Основное меню получает ссылку на раздел;
если ссылка уже настроена в редактируемой шапке сайта, используется её название.
В обычном каталоге отмеченные записи также сохраняются.

Гостям доступны заглавие, подзаголовок, авторы, год, аннотация и выбранная обложка.
Публичные API каталога и поиск по ISBN возвращают ту же сокращённую карточку.
После входа через существующий университетский аккаунт доступны полное описание
и PDF.js-просмотрщик library (листание, масштаб, полноэкранный просмотр). Кнопки
скачивания нет. Это просмотр через браузер, а не DRM: полученный браузером документ
технически можно сохранить. Прогресс чтения для файлов UTBLib пока не сохраняется.

## Хранение и доступ

Миграция `0023_catalog_files` добавляет два флага `records` и таблицу `catalog_files`.
PDF и JPEG первой страницы находятся в PostgreSQL и входят в обычный `pg_dump`.
Существующие записи не помечаются автоматически; каталог, экземпляры, КСУ и
читатели не переносятся и не переписываются.

`POST /api/catalog-files?filename=...` принимает бинарный `application/pdf` с
обычной сессией сотрудника, CSRF и правом `catalog.edit`. Файл проверяется PDFium
в отдельном процессе с лимитами CPU, памяти (Linux), времени и размеров картинки.
Защищённые паролем/нечитаемые PDF отклоняются. До сохранения загрузка привязана
к сотруднику и доступна только через одноразовую связь в `RecordInput.digital_upload`.
Чужая/просроченная загрузка отклоняется. Версия записи защищает от перезаписи
параллельных изменений. Неиспользованные загрузки старше суток убираются при
следующей загрузке; максимум 10 незавершённых загрузок на сотрудника.

`GET /api/public/v1/book-covers/utblib-ID` выдаёт только JPEG и только для отмеченной
записи с включённой обложкой. Исходный PDF не имеет публичного URL или пути в static.
`GET /api/student/v1/books/utblib-ID` и `/file` требуют короткоживущую HMAC-подпись
существующего `STUDENT_BRIDGE_KEY`, привязанную к методу, пути, query и университетскому
subject. Для чтения достаточно подтверждённой университетской учётной записи,
отдельная связь с читательским билетом не требуется. Подпись проверяется на каждом
запросе, включая диапазоны PDF. Ответы имеют `private, no-store`.

library проверяет активность и соответствие `ad_object_guid` серверной сессии
`library.ad_subject`; эти поля также используются существующим входом через Платонус.
В браузер интеграционный ключ не передаётся. Путь `/utblib-books/ID/read` использует
существующие `digital-viewer.blade.php`, `digital-reader.js` и локальный PDF.js.
`/utblib-books/ID/file` проксирует только подписанный запрос, поддерживает Range,
отдаёт `inline`, `nosniff` и запрещает кэширование. Старые локальные документы library
не используются для идентификаторов UTBLib.

## Выпуск

Потребуются оба репозитория. Перед выпуском — резервная копия PostgreSQL. Собрать
UTBLib api/web с фактическими Compose overlays/env, применить Alembic при штатном
старте API; обновить library и очистить кэш представлений/приложения штатным способом.
Новый пакет — `pypdfium2==5.7.0`. Внутренний nginx web допускает запросы до 52 МБ;
внешний прокси должен пропускать PDF до 50 МБ. Новые секреты не нужны, используется
действующий мост reader/student. Не выполнять повторный импорт каталога.

## Проверка локально

1. UTBLib `http://localhost:8096`: открыть запись, отметить «Труды ППС», выбрать PDF,
   включить обложку и сохранить.
2. library `http://localhost:8098/faculty-works?lang=ru`: запись находится поиском,
   обложка видна, гостевая карточка предлагает вход через Платонус.
3. После входа открыть полную карточку и «Читать»; проверить листание и масштаб.
4. Открыть ссылку на файл в приватном окне: доступ должен быть закрыт.
5. Заменить/убрать PDF, отключить обложку или «Труды ППС», сохранить — проверить результат.

Автоматические проверки используют изолированные базы и синтетические PDF:
`backend/tests/test_catalog_files.py`, `frontend/tests/publication-browser.mjs`,
`tests/Feature/UTBLibFacultyWorksTest.php` в library. Рабочая база не наполняется
тестовыми книгами. Документация PDFium: https://pypdfium2.readthedocs.io/en/stable/python_api.html.
